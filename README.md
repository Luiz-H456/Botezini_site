# Botezini — Reposicionamento B2B (2025)

Este repositório contém o código-fonte principal e os documentos de referência para o novo catálogo digital da Botezini, focado em soluções industriais B2B.

## Estrutura do Projeto

- **`/src`**: Contém os arquivos de produção.
  - `index.html`: Página principal com as novas linhas (Operação, Saúde, Corporativa, Essencial).
  - `css/style.css`: Design System (Black/Gold).
  - `js/script.js`: Lógica de UI e animações.
  - `assets/img/`: Imagens e ícones técnicos.
- **`/referencias`**: Versões anteriores, snippets e manuais de marca para consulta.
  - `drafts/`: Rascunhos e modelos obsoletos.
  - `assets_legacy/`: Arquivos originais e compactados.

## Como visualizar
Abra o arquivo `src/index.html` em qualquer navegador moderno.
